# Garden Defense

## Опис

піксельна 2д гра з видом зверху в жанрі товер дефенс геймплей: є 12 на 7 клітки по ним будуть йти монстри треба ставити бойові рослини для захисту, є валюта: це листя за них можна ставити на поле рослини ця гра подібна до впз

## Особливості

* система посадки рослин
* система різноманітя монстрів (покащо тільки 3 види зомбі)
* система ресурсів (листя)
* бойова система для рослин і монстрів
* система здоров'я для рослин
* система здоров'я і защити для монстрів
* система хвиль і ускладненя 
* меню гри (не дороблене)
* система збереженя прогресу (в розробці)
